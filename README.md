# GPT Dreamcore Album

Ứng dụng album ảnh và video phong cách Dreamcore dành cho Android.

## Tính năng
- Album ảnh và video
- Chọn nhiều tệp từ thiết bị Android
- Lưu dữ liệu trên thiết bị bằng IndexedDB
- Lọc ảnh/video và xem toàn màn hình

## Build APK
Mã nguồn Android nằm trong thư mục `android/`. GitHub Actions sẽ tự động build APK debug khi push lên nhánh `main` hoặc chạy workflow thủ công.
